# KreuswortKreuz
Unsere SWE-Arbeit

# Die Modulen dieses Programm:
- Oberfläsche 
- Validierungsmodul
- Rätsel-Editor

- Oberfläsche:
Dieses Modul wird für die visuelle Ausgabe verantwortlich. Mindest Funktionen: 
Erste Ausgabe des ungelösene Rätsel, zweite Ausgabe des gelösene Rätsel mit Funktion die Wörte in sich zu bekommen

- Validierungsmodul:
Dieses Modul soll validieren, ob das Wort zu dieser Reihe oder Zeile passt. Mindest Funktionen:
Die Funktion, die die Werte von Reihe/Zeile empfängt und eine Bool-Werte zurücksendet

- Rätsel-Editog:
Dieses Modul wird den Tabelle bearbeiten, die Wörte aus dem Wörtebuch überprüfen und dann am Ende sendet es die Werte an die Oberfläsche als gelösene Rätsel.
